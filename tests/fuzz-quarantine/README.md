Shaders of `cargo xtask fuzz --random` whose glslang module hangs, resets or crashes the driver of an exec target, confirmed alone, and family references whose image on a target differs by more than one level from the image the other targets agree on (`reference-differs`): `<target>/<mode>/<family>-<shader>-<hash>/` holds the shader, its `.json` shader job and `reason.toml` (verdict, messages of both runs, exit, seed, generator hash, date, driver, `other_targets` with the draw time of the same module on the targets where it runs, so that a module that never ends on one driver is told from a heavy draw, and `rechecked` once `cargo xtask fuzz --recheck-quarantine` confirmed it again); an entry whose family template in `rglsl-fuzz/tests/data/450` changed is removed, since the generator no longer produces its text (a test checks this for references); `<mode>` is `O0` (glslang) or `O` (glslang -O), and rglsl does not run a shader with the same text and job on that target in that mode. A reference quarantined in `O` only leaves its family qualified in `O0`; the `O` shaders of a family are compared with its `O0` reference, so a reference quarantined in `O0` disqualifies both modes.
