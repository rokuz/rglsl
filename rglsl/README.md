# rglsl

The rglsl compiler library: a Vulkan GLSL (`#version 450`/`460`) frontend, an IR with a
validator, and a SPIR-V backend. See the [repository README](../README.md) and
[docs/PLAN.md](../docs/PLAN.md).

rglsl started as a hard fork of [naga](https://github.com/gfx-rs/wgpu/tree/trunk/naga);
see [UPSTREAM.md](../UPSTREAM.md).
